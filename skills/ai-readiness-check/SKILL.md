# AI readiness with DomainScope

1. Use the **AI readiness** tool for a domain: readiness score, `llms.txt` and bot policy.
2. Use the **AI catalog** tool to see a domain's AI catalog and its MCP endpoints.
3. To find companies that host MCP servers, use the **MCP server search** tool with a keyword.

## How to report it

- Give the score and what produced it (for example `llms.txt` present, bot policy). A score is a summary, not a guarantee of how the
  site behaves.
- Name the endpoints exactly as returned. Do not invent endpoints and do not connect to one unless the user asks.
