# Company research with DomainScope

Use the DomainScope tools to build a short, honest profile of a company from its website.

1. **Find the domain.** If the user gave a company name instead of a domain, use the DomainScope identify tool to find it. If it
   returns several candidates, say which one you picked and why, and name the runners-up so the user can correct you.
2. **Read the profile.** Use the domain profile tool for category, industry, size band, technology, security grade and AI posture.
3. **Add the detail the question needs.** The company signals tool gives headcount band, founded year, listing status and
   executives where known. The tech stack tool gives the CMS, eCommerce platform, CDN, hosting network and support stack.
4. **Look at similar sites only if asked, or if it helps.** The similar-domains tool returns sites in the same category and
   industry. Present them as similar sites, never as verified competitors.

## How to report it

- Lead with one sentence on what the company does, then size, then technology, then similar sites.
- A field that comes back empty is "not available in DomainScope". Do not fill the gap from memory and do not guess numbers.
- The data is stored, not live, and coverage varies by domain. Category, industry and similarity labels are generated by AI
  and automated services: call them a strong starting point, not a verdict.
- The security grade describes the website's security setup. Do not present it as a judgement of the company.
- Say the facts came from DomainScope.
