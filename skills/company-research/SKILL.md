# Company research with DomainScope

Use the DomainScope tools to build a short, honest profile of a company from its website.

1. **Get the domain right first.** The profile tools take a domain such as `stripe.com`. If the user gave only a company or brand name,
   use the identify tool (`domainscope_identify_domain`, parameter `query`). It returns the best match with a confidence (high, medium
   or low), the evidence and other candidates. Name matching only: it does not find a company from a description of what it does.
   - High confidence: say which domain you are using and go on.
   - Medium or low confidence, or "no confident match": a low-confidence answer is a guess. Show the candidates and let the user pick
     before you report anything. Do not carry on with a guess.
2. **Read the profile.** Use the domain profile tool (`domainscope_get_domain_profile`) for the stored category, industry, and, where
   collected, company size, hosting network, security grade and AI posture.
3. **Add company signals.** The company signals tool (`domainscope_get_company_signals`) gives headcount band, founded year, listing
   status, stock exchanges and executives where known. Many domains have none.
4. **Add the AI catalog if it matters.** The AI catalog tool (`domainscope_get_ai_catalog`) says whether DomainScope has a record of an AI
   catalog or MCP server. For a readiness summary, use the `ai-readiness-check` skill.

## What this skill cannot do

DomainScope does not offer, through this connector, a company-name or keyword search over its catalog, a list of similar sites, a
technology-stack lookup or a change history. If the user asks for those, say so plainly and do not answer them from memory or guesses.
Only report technology fields if the profile answer itself contains them.

## How to report it

- Lead with one sentence on what the site is about, then industry, then company signals.
- A field that comes back empty is "not available in DomainScope". Do not fill the gap from memory and do not guess numbers.
- Headcount is a stored figure with no guarantee of being current. Give its year if the answer shows one, and call it a rough figure.
- The data is stored, not live, and coverage varies by signal and by domain. Category and industry labels are generated by AI and
  automated services: call them a strong starting point, not a verdict.
- The security grade, if shown, describes the website's security setup. Do not present it as a judgement of the company.
- Say the facts came from DomainScope.
