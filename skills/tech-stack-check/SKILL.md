# Technology check with DomainScope

1. Use the **tech stack** tool for the domain: CMS, eCommerce platform, CDN, hosting network, support stack and security grade.
2. If the user asks what changed, use the **change history** tool for the domain.

## How to report it

- List what was detected. Do not call anything outdated or end-of-life unless the user supplies the vendor's support dates: the tools do not say.
- These are signals read from the site, not an audit. Say so, and suggest the user confirm anything important with the company.
- If the domain is not in DomainScope the tools say so; tell the user plainly instead of guessing.
